# README

## A note on responsiveness

This project is designed to *look good* on resolutions close to 1080p, and *be functional* on other resolutions. Since TOP specifically instructs us not to worry about responsiveness until later in the curriculum, that is as far as I will take it. For example, if the window height is small enough to produce a scroll bar, parts of the intended appearance will break, but the form layout is preserved.
